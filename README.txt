KUNIM — o'rnatiladigan ilova (PWA)

Fayllar: index.html, manifest.webmanifest, sw.js, icon-*.png
Muhim: PWA faqat HTTPS (yoki localhost) orqali ishlaydi, faylni to'g'ridan-to'g'ri ochsangiz o'rnatilmaydi.

1) Hostga qo'ying (bepul): netlify.com/drop yoki GitHub Pages — butun papkani yuklang.
2) Telefonda havolani Chrome (Android) yoki Safari (iPhone) da oching:
   Android: ⋮ → "Ilovani o'rnatish". iPhone: Ulashish → "Bosh ekranga qo'shish".
3) Ilovani ochib, "⏰ Yoqish" tugmasini bosing (ovoz va bildirishnoma ruxsati).

Cheklov: budilnik ilova ochiq turganda ishonchli chaladi. Ilova yopiq bo'lsa brauzer budilnik chalishga ruxsat bermaydi.
